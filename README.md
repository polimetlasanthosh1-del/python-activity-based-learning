# Python Case Studies – README

## Introduction
This project contains 10 Python programs based on real-life problems. It uses basic Python concepts such as variables, operators, conditional statements, loops, lists, and tuples.

## Topics Covered
1. **University Scholarship Allocation** – Select and rank eligible students.
2. **Electricity Billing** – Calculate bills using consumption slabs.
3. **Hospital Billing** – Calculate patient bills and concessions.
4. **Employee Payroll** – Calculate salary, deductions, and net pay.
5. **Mobile Plan Optimization** – Find the most economical mobile plan.
6. **Railway Fare Calculator** – Calculate passenger fares and concessions.
7. **Retail Billing** – Calculate product costs, taxes, and discounts.
8. **Manufacturing Analysis** – Calculate production costs and profit.
9. **Travel Budget Analysis** – Convert expenses and check the budget.
10. **Campus Event Planning** – Calculate event costs and break-even registrations.

## Objectives
- Understand basic Python programming.
- Develop logical thinking and problem-solving skills.
- Apply conditions, loops, lists, and tuples to real-world problems.

## Requirements
- Python 3
- Any Python editor, such as IDLE or VS Code.

## Conclusion
These programs help beginners learn Python through simple, practical examples.
